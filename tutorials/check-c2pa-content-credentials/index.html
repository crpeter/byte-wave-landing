How to Check C2PA Content Credentials in ByteWave

By ByteWave · Updated September 28, 2026

AI disclosure: This article includes text generated with an AI language model (LLM). Published by ByteWave, which makes the app discussed here.

Check a photo or video

  1. Import the original file into ByteWave. Check it before editing or removing metadata.
  2. Select the clip. If its badges are hidden, tap the hexagon labeled Show Badges.
  3. Tap the provenance badge to see the result and details.

What the result means

ResultMeaning
Verified AI-generatedByteWave verified a signed record identifying the file as AI-generated.
Likely syntheticMetadata suggests synthetic content. This is an estimate.
Likely camera captureMetadata suggests camera capture. This is an estimate.
UnverifiedThere is not enough verified evidence to establish the file’s origin.
ByteWave VerifiedByteWave’s signed history and source assessments are present. This is separate from an AI-generation label.

No credentials?

That does not mean real or fake. Credentials can be missing, removed, or unsupported. Try the original file if you have it.

A signature cannot prove a scene happened, and a score is not a percentage chance that it is real. About C2PA.
