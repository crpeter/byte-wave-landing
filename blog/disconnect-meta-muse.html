Deleting an app is not a complete exit. Close the connections too.

1. Disconnect your services in Muse.

Stop assigning tasks. Open Muse’s connection settings and disconnect the services you linked. Meta says you can disconnect services at any time. Menu names can vary; this guide does not assume one screen layout.

2. Revoke access at the account itself.

For Google, open your linked apps. Find the Muse connection that has access to your Google Account, review its details, and choose Remove access. Confirm. Removing a sign-in link alone is a different action. Google’s instructions.

Repeat in each other connected service’s account or security settings. Check active sessions too if you signed in through Muse’s browser. Revoke any API keys you created specifically for Muse.

3. Deal with stored data separately.

Save anything you need before deleting it. Review Muse’s current data-deletion controls and the retention terms shown there. Check saved files, conversations, memories, credentials, and scheduled tasks; do not assume removing one removes the others.

Meta describes data and connected credentials stored in Muse’s cloud computer. Revoking access does not prove that previously copied data has been erased. It also cannot recall messages already sent.

4. Check, then uninstall.

Revisit your accounts to confirm access is removed. Review Muse’s device permissions before uninstalling. These are steps for leaving, not a promise that using Muse can be made risk-free.
