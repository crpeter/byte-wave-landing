인터넷을 끄고 영상 한 편을 완성해 보자. 개인정보 보호를 내세운 광고보다 직접 해 본 결과가 더 많은 것을 알려 준다.

ByteWave의 기기 내 편집기는 계정이 필요 없다. iPhone에서 기본적인 오프라인 편집 과정을 확인하는 방법이다.

기기에 실제로 있는 클립으로 시작하기

온라인에서 ByteWave를 설치한다. 기기에 이미 내려받은 짧은 영상을 고르거나 새로 촬영한다. iCloud 썸네일이 있다고 전체 영상이 기기에 저장된 것은 아니다.

이 테스트에서는 앞이나 뒤를 조금 자르면 된다. 자동 자막까지 써 보려면 필요한 음성 또는 언어 모델을 미리 내려받는다.

인터넷을 끄고 편집하기

  1. 에어플레인 모드를 켠다. 설정에서 Wi-Fi도 끈다. Apple에 따르면 에어플레인 모드에서도 Wi-Fi가 켜져 있을 수 있다.
  2. 로그인 없이 ByteWave를 연다. 기기에 저장된 클립을 선택한다.
  3. 조금 편집한다. 앞부분이나 끝부분을 자른다.
  4. 사진 앱에 저장한다. 오프라인 상태로 사진 앱에서 저장된 영상을 열어 재생한다.

이로써 기기에서 편집하고 내보낼 수 있는지 직접 확인했다. 끝나면 다시 연결한다.

이 테스트로 확인할 수 있는 것

이 과정에 인터넷이 필요한지 확인하는 테스트다. 모든 계정 정지 상황을 재현하거나 모든 편집기의 모든 기능이 오프라인에서 작동한다고 증명하지는 않는다.

ByteWave에 게시하거나 다른 사람이 공유한 영상을 찾으려면 연결이 필요하다. 자동 자막은 기기에서 처리한다. 영상을 찾기 쉽게 하는 자동 태그는 계정이 필요한 별도의 선택 기능이다. 개인정보 처리방침을 참고하자.

사진 앱에 저장한 모든 영상에는 ByteWave의 보이지 않는 출처 표시가 들어간다. 화면에 보이는 워터마크는 없다.

원본과 완성본을 모두 보관하기

원본 클립과 내보낸 영상을 보관하자. 내보낸 파일은 결과물이지 다시 편집할 수 있는 프로젝트 백업이 아니다. 중요한 자료는 따로 백업한다.

내 영상을 다시 열 수 있는 방법이 계정 하나뿐이어서는 안 된다.

관련 글: 계정 없이 편집하기, 연결 기능이 사라진 뒤에도 남는 것.
