ByteWave는 Apple의 기본 번역 시스템으로 동영상 자막을 번역할 수 있습니다. 정확한 자막을 준비한 다음 원문 언어와 지원되는 번역 언어를 선택하세요. 원본 텍스트와 자막 표시 타이밍이 유지되므로 내보내기 전에 번역을 비교할 수 있습니다.

검토한 자막부터 준비하기

동영상 프로젝트를 열고 자막을 선택하세요. 자막으로 만들 음성에서 자막을 생성한 뒤 원문을 검토하세요. 이름, 숫자, 잘못 인식된 단어는 번역 전에 수정하세요. 번역이 음성 인식 오류를 확실하게 바로잡아 주는 것은 아닙니다.

자막이 보이는 상태로 클립을 재생하세요. 각 문구가 말하는 순간에 표시되는지 확인하세요. 텍스트를 완성한 뒤 스타일과 움직임을 적용하는 방법은 움직이는 자막 가이드를 참고하세요.

원문 언어와 번역 언어 선택하기

  1. 자막의 번역 컨트롤을 여세요.
  2. 번역할 원본에서 원본 언어를 열고 원본 자막 텍스트의 언어를 선택하세요. 휴대전화의 인터페이스 언어가 아니라 실제 글의 언어를 선택해야 합니다.
  3. 번역할 언어에서 대상 언어를 탭하세요. 탭하면 번역이 시작되며 별도의 확인 버튼은 없습니다.
  4. 필요한 언어 다운로드를 허용한 뒤 자막 번역 완료가 표시될 때까지 기다리세요. 중단하려면 취소를 사용하세요.

이 컨트롤의 이름은 앱의 표시 언어에 맞게 번역됩니다. 선택할 수 있는 번역 언어는 Apple의 시스템 지원에 따라 정해지며 원문과 같은 언어는 제외됩니다. ByteWave의 인터페이스 언어 목록과 자막 번역 언어 목록은 서로 다릅니다.

기기에서 사용할 언어 준비하기

ByteWave는 기기 내 언어 모델을 사용하는 Apple의 Translation 프레임워크를 이용합니다. 필요한 언어가 설치되어 있지 않으면 시스템에서 다운로드를 요청할 수 있습니다. 다운로드하려면 인터넷 연결이 필요하므로 오프라인 작업 전에 언어를 준비하세요.

Apple의 번역 앱이 설치되어 있다면 설정 → 앱 → 번역에서 언어 다운로드를 관리할 수 있습니다. 언어 다운로드 항목의 이름은 iOS 버전에 따라 다를 수 있습니다. Apple의 언어 다운로드 안내와 기기 내 번역 모델에 대한 설명을 참고하세요. 기기에서 Apple이 지원하는 언어여야 합니다. 다른 키보드를 다운로드한다고 번역 지원이 추가되지는 않습니다.

번역과 원문 비교하기

원문 미리보기를 켜면 번역을 삭제하지 않고 원문을 비교할 수 있습니다. 끄면 번역된 자막을 다시 확인할 수 있습니다. 번역 제거는 원본 자막을 유지하면서 번역만 삭제합니다.

표시 타이밍은 유지되지만 번역된 문구가 더 많은 공간을 차지할 수 있습니다. 클립 전체에서 줄바꿈, 글자 크기, 위치를 확인하세요. 이름, 속어, 짧은 문구는 번역 언어를 이해하는 사람이 꼼꼼하게 검토하는 것이 좋습니다.

번역이 시작되지 않을 때

  • 원본 언어를 선택하지 않은 경우: 먼저 번역할 원본에서 언어를 선택하세요.
  • 번역 언어가 없는 경우: Apple의 현재 지원 언어와 기기에서 사용할 수 있는 시스템 리소스를 확인하세요. ByteWave는 모든 언어나 모든 지역별 언어 조합을 지원한다고 보장하지 않습니다.
  • 언어 다운로드가 필요한 경우: 다시 연결하여 다운로드를 마친 뒤 재시도하세요.
  • 번역 중 자막이 변경된 경우: 텍스트 편집을 마친 뒤 다시 번역하세요.
  • 텍스트가 그대로인 경우: 원본 언어를 확인하세요. 이름은 바뀌지 않을 수 있으며 텍스트가 이미 번역 대상 언어로 되어 있을 수도 있습니다.

검토하고 내보내기

번역을 표시하려면 원문 미리보기를 끄고 편집한 동영상 전체를 재생한 뒤 내보내세요. 공유하기 전에 내보낸 파일을 열어 자막을 한 번 더 확인하세요. 이 과정은 자막 텍스트를 번역하며, 말소리를 더빙 음성으로 바꾸지는 않습니다.

ByteWave의 모든 편집 도구는 무료입니다. 구독이 필요 없고 내보낸 영상에 눈에 보이는 ByteWave 워터마크도 없습니다. 이어서 자막 텍스트 효과 또는 오디오 반응형 효과 가이드를 확인하세요.
