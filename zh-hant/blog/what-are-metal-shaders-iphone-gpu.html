在大多數影片編輯器套用濾鏡時，背後會發生你看不到的處理。App 取得每個影格，透過某種演算法處理，再交出結果。在多數 App 裡，這個演算法是黑盒子；在 ByteWave 裡，它是你真的能閱讀和修改的 Metal 著色器。

什麼是 Metal？

Metal 是 Apple 的 GPU 程式設計框架。CPU 和 GPU 都會平行執行工作，但 GPU 特別適合對大量像素套用類似的操作。4K 影格有超過八百萬個像素；GPU 會安排多組執行緒處理，而不是讓每個像素同時執行。

Metal 在 Apple 平台取代了 OpenGL，讓開發者能更直接控制硬體。Apple 裝置上的高階遊戲與專業創作工具也使用同一套框架。

什麼是著色器？

著色器是在 GPU 上執行的小程式。在影片編輯中，它接收像素顏色並輸出新顏色，這就是最基本的概念。灰階著色器會讀取像素的紅、綠、藍數值，取平均後得到單一灰階值。色調著色器會改變色相。模糊著色器則取樣周圍像素並混合。

以下是一個簡短的 Metal 運算範例。它假設輸入與輸出紋理大小相同，示範的是 Metal 語法，而非 ByteWave 的自訂濾鏡介面：

#include <metal_stdlib>
using namespace metal;

kernel void grayscale(
    texture2d<float, access::read> input [[texture(0)]],
    texture2d<float, access::write> output [[texture(1)]],
    uint2 pixel [[thread_position_in_grid]]) {
    if (pixel.x >= input.get_width() || pixel.y >= input.get_height()) return;
    float4 color = input.read(pixel);
    float gray = dot(color.rgb, float3(0.2126, 0.7152, 0.0722));
    output.write(float4(gray, gray, gray, color.a), pixel);
}

每個執行緒處理一個像素。特效能否跟上播放速度，取決於裝置、解析度與著色器。Apple 的 Metal 範例程式碼包含以運算核心處理影像的示例。

為什麼這對影片編輯很重要？

大多數行動影片編輯器使用預先編譯的程式碼套用濾鏡，你無法查看或修改。你得到「復古」濾鏡或「暖色」預設，也許能用滑桿調整強度，僅此而已。你不知道濾鏡實際做了什麼，也不能修改底層邏輯。

ByteWave 採用不同做法。每個濾鏡都提供著色器原始碼。打開程式碼檢視，即可準確看見灰階、印象派或其他特效在像素層級做了什麼。更重要的是，你可以改變它。

能辨識主體的著色器

ByteWave 更進一步，讓著色器存取 Vision 框架的資料。App 可偵測影片主體並傳送遮罩給著色器，讓主體與背景有不同處理。背景變成印象派畫作，主體保持清晰；主體套用調色，背景降低飽和度；除了臉部之外全部模糊。這些效果在傳統流程中需要於 After Effects 手動轉描。
