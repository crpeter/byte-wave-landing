## Comparison plan labels verified October 18, 2026

The Pro guide lists motion blur and desktop image noise reduction in Pro. The separate motion-blur tutorial advertises free variants; the comparison keeps that caveat. The caption help page describes Pro-only functionality and Pro for full access. The mobile upscaling guide states AI features require a subscription without naming the plan. The optical-flow tool page advertises free trials. Premium text-to-speech uses credits.
