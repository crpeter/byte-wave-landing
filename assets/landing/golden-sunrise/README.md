This credit records the source for ByteWave's website background. The photograph
is not exclusive to ByteWave.

The WebP files retain the original 3:2 composition at 1280, 1920, 2560, and 3840
pixels wide. They were resized from the original with ImageMagick, metadata
stripped, and encoded at quality 90 with WebP method 6. The 3840 × 2560 version
supports a 3840 × 2160 landscape crop without upscaling. CSS keeps the rising sun
in view on portrait screens and provides a dark overlay behind the white text.

The preload and image use matching responsive candidates. Their sizes account
for the width needed to cover a tall hero with a landscape photo, rather than
selecting a low-resolution image based only on the narrow viewport width.
