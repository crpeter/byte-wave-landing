In ByteWave können Sie Shader-Code bearbeiten und eigene Filter erstellen. Jetzt können Sie Ihre Filter teilen und die anderer Filmschaffender nutzen. So wird der Shader-Editor zum gemeinsamen Werkzeug.

So funktioniert es

Veröffentlichen Sie einen Filter mit einem Fingertipp. Andere können ihn finden, in der Vorschau testen und in ihre Sammlung aufnehmen. Auch Sie können in der Community stöbern und deren Filter in jedem Projekt verwenden.

Jeder Filter läuft auf der GPU Ihres Geräts. Beim Veröffentlichen teilen Sie den Shader-Code. Ihre Aufnahmen bleiben auf dem Gerät.

Einen Filter veröffentlichen

Erstellen Sie einen Filter oder passen Sie einen an. Beginnen Sie von vorn, ändern Sie einen vorhandenen Effekt oder erstellen Sie mit KI einen neuen.

Tippen Sie auf Veröffentlichen. Geben Sie einen Namen und eine kurze Beschreibung ein. Jetzt können andere den Filter in der Community-Bibliothek finden.

Filter entdecken

Stöbern Sie in der Community-Bibliothek. Probieren Sie Effekte an eigenem Material aus und speichern Sie Ihre Favoriten.

Verwenden oder kombinieren Sie Filter. Community-Filter stehen neben integrierten und eigenen Filtern. Sie können sie anwenden, stapeln oder ihren Code als Ausgangspunkt nehmen.

Warum Filter teilen?

Viele Schnittprogramme liefern feste Vorlagen. Die Sammlung von ByteWave wächst mit den Beiträgen der Community. Teilt jemand eine VHS-Störung oder einen Kodachrome-Look, können ihn alle mit einem Fingertipp hinzufügen.

Community-Shader zu lesen, anzupassen und erneut zu veröffentlichen ist auch eine praktische Einführung in die GPU-Programmierung.

Was kommt als Nächstes?

Dies ist die erste Version. Suche, Kategorien und kuratierte Sammlungen sind Ideen für die Zukunft. Schon heute können Sie Filter erstellen, teilen und wiederverwenden.
