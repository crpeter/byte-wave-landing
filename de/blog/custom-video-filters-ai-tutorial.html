In ByteWave können Sie den Code eines Filters ansehen, eine Änderung in eigenen Worten beschreiben und einen KI-Assistenten den Code anpassen lassen. So entstehen Effekte jenseits der mitgelieferten Vorlagen.

So funktionieren die Filter in ByteWave

Jeder Filter ist ein Metal-Shader, ein kleines Programm, das jedes Videobild auf der GPU des Geräts verarbeitet. Neben den Reglern steht Ihnen der Quellcode zur Verfügung.

Eigene Filter mit KI erstellen

1. Öffnen Sie einen Filter. Wählen Sie einen ähnlichen Look und tippen Sie auf das Code-Symbol, um den Shader zu sehen.

2. Kopieren Sie die Shader-Referenz. ByteWave stellt die wichtigsten Parameter und die Struktur des Filters zum Kopieren bereit.

3. Beschreiben Sie den Effekt. Fügen Sie die Referenz in ChatGPT, Claude oder einen anderen Assistenten ein. Bitten Sie etwa um den Look eines verblassten Kodachrome-Films der 1970er mit wärmeren Lichtern und tiefen, verdichteten Schatten.

4. Prüfen Sie die Vorschau. Fügen Sie den erzeugten Code in den Filtereditor ein und passen Sie ihn an, bis Ihnen das Ergebnis gefällt.

5. Speichern und verwenden Sie den Filter. Nutzen Sie ihn in jedem Projekt, teilen Sie ihn mit der ByteWave-Community oder stöbern Sie in Filtern anderer Filmschaffender.

Eigene Filter mit Motivmaske

Übergeben Sie dem Shader eine Motivmaske. So können Sie nur den Hintergrund malen, weichzeichnen oder umfärben oder umgekehrt nur das Motiv bearbeiten. Früher war dafür oft Rotoskopie in After Effects nötig.

Ideen zum Ausprobieren

🎨 Wes Anderson: symmetrische Pastellkomposition mit kräftigeren Gelb- und Rosatönen.

🕵️ Film noir: kontrastreiches Schwarz-Weiß mit deutlicher Vignette.

🌊 Unter Wasser: blaugrüne Töne mit feinen Mustern gebrochenen Lichts.

📼 VHS-Störung: Scanlinien, auslaufende Farben und Bildverzerrungen durch Spurfehler.

🌅 Goldene Stunde: warme bernsteinfarbene Lichter mit weicher Streuung.

Beschreiben Sie das gewünschte Bild, um über die Vorlagen des Designteams hinauszugehen.
