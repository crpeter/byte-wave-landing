Essayez de terminer une vidéo sans connexion. Vous en apprendrez plus qu’en lisant une promesse de confidentialité.

Le montage local dans ByteWave ne nécessite pas de compte. Voici comment tester les étapes de base sur votre iPhone.

Partez d’un clip réellement disponible

Installez ByteWave pendant que vous êtes en ligne. Choisissez un court clip déjà téléchargé sur l’appareil ou filmez-en un. Une vignette iCloud ne remplace pas la copie locale de la vidéo entière.

Pour cet essai, raccourcissez simplement le clip. Pour tester aussi les sous-titres automatiques, téléchargez au préalable les modèles vocaux ou linguistiques nécessaires.

Essayez sans internet

  1. Activez le mode Avion. Dans Réglages, désactivez aussi le Wi-Fi. Apple précise que le Wi-Fi peut rester actif en mode Avion.
  2. Ouvrez ByteWave sans vous identifier. Choisissez le clip présent sur l’appareil.
  3. Faites une petite modification. Coupez le début ou la fin.
  4. Enregistrez dans Photos. Toujours hors ligne, ouvrez la vidéo enregistrée dans Photos et lancez la lecture.

Vous venez de vérifier concrètement le montage et l’export locaux. Rétablissez la connexion une fois l’essai terminé.

Ce que vérifie cet essai

Il vérifie si ce parcours précis nécessite une connexion. Il ne simule pas toutes les suspensions de compte et ne prouve pas que toutes les fonctions de tous les logiciels marchent hors ligne.

La publication et la découverte de vidéos partagées sur ByteWave exigent une connexion. La création automatique de sous-titres s’effectue sur l’appareil. Le balisage facultatif pour la découverte est une fonction distincte nécessitant un compte. Voir la politique de confidentialité.

Chaque export vers Photos contient le sceau de provenance invisible de ByteWave. Aucun filigrane visible n’est ajouté.

Gardez les deux types de copie

Conservez les clips originaux et les exports terminés. Une vidéo exportée conserve le résultat, sans constituer une sauvegarde modifiable du projet. Sauvegardez séparément les éléments importants.

Votre compte ne devrait pas être votre seul accès à vos images.
