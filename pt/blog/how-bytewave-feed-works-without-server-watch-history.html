Quatro etapas do tratamento de dados

1. Editar. As filmagens originais ficam no processo de edição local e não são enviadas para o ByteWave.
2. Autenticar. Os perfis opcionais utilizam o Firebase Authentication. Os dados de autenticação são distintos das filmagens.
3. Publicar. Um vídeo só é enviado quando o utilizador escolhe publicar ou partilhar através de uma função online.
4. Navegar. Os sinais de recomendação e o histórico de vídeos de que gostou ficam no dispositivo. O ByteWave não recebe um histórico de visualização no servidor.

Sem perfil

É possível editar e renderizar localmente e percorrer o feed público de forma anónima. O ByteWave não guarda histórico de visualização no servidor, com ou sem sessão iniciada.

O que muda com um perfil

O perfil permite participar em funcionalidades sociais opcionais. O Firebase Authentication trata da autenticação. Os conteúdos publicados e os dados do perfil utilizam serviços online. Isto não transforma a edição local num processo de envio das filmagens.

Personalização e gostos

As recomendações personalizadas são opcionais e calculadas no dispositivo. O histórico de vídeos de que gostou, descrito na política de privacidade, também é guardado localmente. Criar um perfil não transforma esses registos num histórico de visualização no servidor.

Legendas e etiquetas de descoberta

A transcrição para legendas decorre no dispositivo sem conta. A etiquetagem automática é uma funcionalidade distinta e opcional que combina reconhecimento de voz e análise visual para facilitar a descoberta de vídeos partilhados. Exige uma conta e permissão para reconhecimento de voz. A transcrição para etiquetas também é local. Se o reconhecimento no dispositivo não estiver disponível, a aplicação ignora a etapa de fala sem enviar áudio para transcrição. Consulte a política de privacidade.

O que demonstra esta arquitetura

O ByteWave pode oferecer edição local e personalização opcional do feed sem conservar o histórico de visualização no servidor nem usar dados comportamentais para publicidade direcionada. Uma menor recolha de dados não demonstra, por si só, bem-estar, segurança das crianças ou ausência do risco de utilização compulsiva.
