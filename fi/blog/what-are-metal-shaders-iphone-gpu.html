Kun käytät suodatinta useimmissa videoeditoreissa, taustalla tapahtuu jotain näkymätöntä. Sovellus käsittelee videon jokaisen ruudun algoritmilla ja näyttää tuloksen. Tavallisesti algoritmi on musta laatikko. ByteWavessa se on Metal-varjostin, jota voit lukea ja muokata.

Mikä Metal on?

Metal on Applen GPU-ohjelmointikehys. Sekä CPU että GPU suorittavat töitä rinnakkain, mutta GPU sopii erityisesti samankaltaisiin operaatioihin monille pikseleille. 4K-ruudussa on yli kahdeksan miljoonaa pikseliä. GPU ajoittaa säieryhmiä käsittelemään niitä sen sijaan, että suorittaisi kaikki pikselit yhtä aikaa.

Metal korvasi OpenGL:n Applen alustoilla ja antaa kehittäjille huomattavasti suoremman laitteiston hallinnan. Sama kehys pyörittää vaativia pelejä ja ammattilaisten luovia työkaluja Apple-laitteilla.

Mikä varjostin on?

Varjostin on pieni GPU:lla toimiva ohjelma. Videoeditoinnissa se saa syötteenä pikselin värin ja tuottaa uuden värin. Tämä on perusidea. Harmaasävyvarjostin lukee punaisen, vihreän ja sinisen arvot ja laskee niiden keskiarvon yhdeksi harmaaksi arvoksi. Värisävyvarjostin muuttaa sävyä. Sumennusvarjostin näytteistää viereisiä pikseleitä ja sekoittaa ne.

Tässä on pieni Metal-laskentaesimerkki. Se olettaa samankokoiset syöte- ja tulostekstuurit ja havainnollistaa Metal-syntaksia, ei ByteWaven omien suodattimien rajapintaa:

#include <metal_stdlib>
using namespace metal;

kernel void grayscale(
    texture2d<float, access::read> input [[texture(0)]],
    texture2d<float, access::write> output [[texture(1)]],
    uint2 pixel [[thread_position_in_grid]]) {
    if (pixel.x >= input.get_width() || pixel.y >= input.get_height()) return;
    float4 color = input.read(pixel);
    float gray = dot(color.rgb, float3(0.2126, 0.7152, 0.0722));
    output.write(float4(gray, gray, gray, color.a), pixel);
}

Jokainen säie käsittelee yhden pikselin. Tehosteen pysyminen toiston tahdissa riippuu laitteesta, tarkkuudesta ja varjostimesta. Applen Metal-esimerkkikoodissa on laskentaytimiin perustuvaa kuvankäsittelyä.

Miksi tämä merkitsee videoeditoinnissa

Useimmat mobiilieditorit käyttävät suodattimissa esikäännettyä koodia, jota et voi nähdä tai muuttaa. Saat ”Vintage”-suodattimen tai ”Lämmin”-esiasetuksen ja ehkä voimakkuussäätimen. Siinä kaikki. Et tiedä, mitä suodatin todella tekee, etkä voi muuttaa sen logiikkaa.

ByteWave toimii toisin. Jokainen suodatin näyttää varjostimensa lähdekoodin. Koodinäkymästä näet tarkasti, mitä harmaasävy-, impressionismisuodatin tai muu tehoste tekee pikselitasolla. Ennen kaikkea voit muuttaa sitä.
